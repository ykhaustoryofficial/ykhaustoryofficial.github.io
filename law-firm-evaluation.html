법무법인 선정 1차 평가 집계

6개 법인 · 평가위원 5명 · 정량 35점 + 정성 35점 = 70점

평가를 마치면 「입력내용 포함 HTML 다운로드」를 눌러 저장하세요. 다른 PC에서는 다운로드한 최신 HTML 파일을 열면 이어서 작성할 수 있습니다.

평가위원 고유번호 관리

평가위원 1~5의 고유번호를 입력하고 저장하세요. 고유번호는 HTML 다운로드 파일과 JSON 백업에 포함됩니다.

법인별 종합 순위

입력된 점수만으로 임시 계산하며, 미입력 항목이 있으면 확정 순위가 아닙니다.

법인별 종합점수 비교

평가점수 직접 입력

빈칸은 미입력입니다. 0점은 실제 0점으로 집계됩니다. 35점 초과 또는 음수는 입력할 수 없습니다. 정량과 정성을 모두 입력한 평가위원만 해당 법인의 종합 평균에 반영됩니다.

집계 기준 및 유의사항

① 정량·정성 각각 35점 만점, 1차 합계 70점 만점입니다.
② 각 법인에 대해 평가위원이 정량과 정성 두 점수를 모두 입력하면 그 위원의 합계점수를 산출합니다.
③ 법인별 평균은 입력 완료된 평가위원의 점수만 대상으로 계산합니다. 모든 평가위원이 입력을 완료하기 전에는 잠정 결과입니다.
④ 소수점 첫째 자리 반올림 표시를 위해 내부 계산은 원점수를 유지하고 표시할 때 소수점 한 자리로 반올림합니다.
⑤ 동점 법인은 공동순위로 표시합니다. 별도 동점 처리 규정이 있다면 최종 결과에 적용해야 합니다.
⑥ 본 화면은 1차 평가 집계용입니다. 2차 PT 30점은 포함하지 않습니다.
⑦ 정량점수는 평가위원별 실제 채점이 아닌 35점 만점 가정입니다. 정성점수와 의견은 제출된 평가위원별 HTML에서 옮겼습니다. 수기 평가위원은 원본에 기재된 참고 페이지 및 메모를 기록했으며, 5번째 평가위원의 의견은 자동 전사 자료로 오탈자 검토가 필요합니다.

평가위원별 항목 점수, 평가 근거, 통합자료 참고 페이지를 기록합니다.

첨부 평가표의 정량·정성 항목과 배점 및 점수 판단기준을 요약했습니다. 세부 근거는 각 항목의 입력란에 기록하세요. 항목별 점수를 입력하면 종합 순위에 자동 반영됩니다. 모든 항목의 점수를 입력해야 평가 완료로 집계됩니다.
